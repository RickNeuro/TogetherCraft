# TogetherCraft — план проекта

Этот файл — основной список задач и ориентир для дальнейшей работы. Новые изменения сначала сверяются с ним. Если задача не описана или требования неоднозначны, сначала уточняем детали.

## Уже реализовано
- [x] Главная страница сообщества и два игровых мира.
- [x] Публичный статус Fabric и Create.
- [x] Регистрация, авторизация и PostgreSQL.
- [x] Одобрение заявок администратором.
- [x] Привязка Minecraft Java-профиля через Microsoft OAuth.
- [x] Отдельные RCON-подключения и whitelist для обоих серверов.
- [x] Ограничение системных метрик для одобренных пользователей.
- [x] Docker Compose, первичная настройка и bootstrap схемы PostgreSQL.
- [x] CI: сборка .NET, проверка Compose, временная PostgreSQL, smoke- и Playwright-тесты.

## Проверить
- [ ] Перенос актуальной версии в main и единый рабочий процесс.
- [ ] Production-конфигурацию и совместимость существующей БД с bootstrap до первого деплоя.
- [ ] Оба Minecraft-сервера, RCON и whitelist на реальной инфраструктуре.
- [ ] Метрики CPU, RAM, диск, температура и FAN1/FAN3 на Ubuntu.
- [ ] HTTPS/прокси и корректное определение IP клиента.

## Следующие задачи
- [ ] Unit-тесты сервисов Minecraft status, RCON, авторизации и метрик.
- [ ] Интеграционные тесты регистрации, одобрения/отклонения и whitelist.
- [ ] Проверка ошибок Microsoft OAuth и недоступности одного из серверов.
- [ ] Диагностика и документация восстановления.

## Правила работы
1. После консолидации основная рабочая ветка — main.
2. Перед изменениями читать этот файл и связанные исходники.
3. Не менять дизайн, конфигурацию серверов и production без согласованной задачи.
4. На каждую исправляемую ошибку добавлять воспроизводящий тест, если возможно.
5. Перед выкладкой должны проходить CI и проверки конфигурации.
6. Production-деплой отдельно включается GitHub variable DEPLOY_ENABLED=true.
7. Не удалять PostgreSQL volumes и не делать разрушительных миграций без backup и плана отката.
