# Настройка автоматического whitelist

Админ-панель отправляет команду Minecraft только после нажатия «Одобрить и добавить в whitelist». Браузер не может обращаться к RCON напрямую, а пароль хранится в локальном `.env` на сервере приложения.

## 1. Найди фактический `server.properties`

Используй каталог, из которого сейчас запускается Fabric. Не создавай второй файл в другой папке: Minecraft читает настройки из рабочего каталога своего текущего сервера.

Перед изменениями останови сервер штатным способом и сделай копию файла `server.properties`.

## 2. Настрой RCON

В `server.properties` выставь `white-list=true`, чтобы список реально ограничивал вход. Также выставь следующие параметры RCON:

```properties
enable-rcon=true
white-list=true
rcon.port=25575
rcon.password=ЗДЕСЬ_ДЛИННЫЙ_УНИКАЛЬНЫЙ_СЕКРЕТ
broadcast-rcon-to-ops=false
```

Задай такой же секрет в `.env` приложения:

```dotenv
RCON_HOST=host.docker.internal
RCON_PORT=25575
RCON_PASSWORD=ТАКОЙ_ЖЕ_ДЛИННЫЙ_УНИКАЛЬНЫЙ_СЕКРЕТ
```

Секрет не должен совпадать с паролем администратора сайта или БД. После изменения настроек перезапусти Minecraft-сервер. Если whitelist раньше был отключён, проверь командой `whitelist list`, что ник появился, и попробуй подключение тестового игрока. Если сервер у тебя запускается не в стандартном рабочем каталоге, не меняй настройки другого `server.properties`.

## 3. Не открывай RCON в интернет

**Не настраивай проброс TCP 25575 на роутере.** RCON должен быть доступен только с доверенной машины/локальной Docker-сети. Если на Ubuntu включён UFW или другой firewall, проверь правила, чтобы порт RCON нельзя было достичь с внешнего интерфейса. Не отключай firewall целиком ради подключения.

`host.docker.internal` в Compose сопоставляется с адресом Docker-хоста. Если текущая установка Minecraft ограничивает RCON только loopback-интерфейсом, контейнер не сможет подключиться; сначала проверь прослушиваемый адрес и firewall, а потом настраивай минимально необходимое разрешение, не публикуя порт наружу.

## 4. Проверка

1. Перезапусти контейнер сайта после изменения `.env`:

   ```bash
   docker compose up -d --force-recreate togethercraft-web
   ```

2. Зарегистрируй тестовый аккаунт с действительным Minecraft Java-ником.
3. Войди администратором и открой «Заявки».
4. Нажми «Одобрить и добавить в whitelist».
5. Убедись, что в логах сайта нет ошибки RCON и что серверный whitelist действительно содержит ник.

Если RCON недоступен или пароль неверный, сайт показывает ошибку, а заявка остаётся `Pending`, чтобы можно было безопасно повторить действие после исправления настройки.
