# Game artwork sources

These images are downloaded into this directory before CI and production builds.
They are original game artwork or faithful renders of in-game models; they are
used only as small game-direction icons. World-cover screenshots remain neutral
placeholders until the owner uploads real TogetherCraft screenshots.

- **Minecraft — mossy cobblestone**: rendered from the Minecraft Java block model
  by [Block Render](https://blockrender.dev/block/mossy_cobblestone/), identified
  by the [Russian Minecraft Wiki](https://ru.minecraft.wiki/w/Замшелый_булыжник).
  Download:
  https://blockrender.dev/render/block/mossy_cobblestone.png?size=512

- **Create — large cogwheel**: actual large cogwheel texture from the
  [Creators-of-Create source repository](https://github.com/Creators-of-Create/Create),
  pinned to commit
  [4148fd8d5b05c85d88947edc00fb495a5074f57d](https://github.com/Creators-of-Create/Create/commit/4148fd8d5b05c85d88947edc00fb495a5074f57d).

- **Factorio — big biter**: original in-game artwork from the
  [official Factorio Wiki file page](https://wiki.factorio.com/File:Big_biter.png).
  The wiki identifies the file as a 189 × 134 PNG sourced from Factorio game
  content and subject to the game's copyright policies.
  Download:
  https://wiki.factorio.com/images/Big_biter.png
