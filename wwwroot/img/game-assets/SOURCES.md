# Game artwork sources

These images are downloaded into this directory before CI and production builds.
They are kept as original source artwork; TogetherCraft does not redraw or recreate
the game marks.

- **Minecraft — mossy cobblestone**: the block is identified by the
  [Russian Minecraft Wiki](https://ru.minecraft.wiki/w/Замшелый_булыжник).
  The local image is a transparent isometric PNG rendered from the Minecraft
  Java block model by [Block Render](https://blockrender.dev/block/mossy_cobblestone/).
  Download:
  https://blockrender.dev/render/block/mossy_cobblestone.png?size=512

- **Create — large cogwheel**: the local image is the actual large cogwheel
  texture from the [Creators-of-Create source repository](https://github.com/Creators-of-Create/Create).
  The source is pinned to commit
  [4148fd8d5b05c85d88947edc00fb495a5074f57d](https://github.com/Creators-of-Create/Create/commit/4148fd8d5b05c85d88947edc00fb495a5074f57d).
  It corresponds to the [Create Wiki cogwheel entry](https://create.fandom.com/ru/wiki/Шестерня).

- **Factorio — logo**: the [official Factorio Wiki file page](https://wiki.factorio.com/index.php?title=File:Factorio-logo.png)
  states that the original PNG comes directly from the Factorio game files and
  is subject to the game's copyright policies.
  Download:
  https://wiki.factorio.com/images/Factorio-logo.png
